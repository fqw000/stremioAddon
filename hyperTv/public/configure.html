HypeTv Stremio Addon

选择数据来源与目录，生成 Stremio 安装链接。配置以 ?cfg= 写入插件地址，不上传服务器。

1. 数据来源

实测：内置列表的直播流返回 403（站点声明仅部分账号开放），因此直播目录默认关闭；电影与剧集可用。

2. 元数据（可选）

站点自身接口固定葡语、不支持语言参数；中文标题/简介/海报由 TMDB language=zh-CN 提供。默认已配置可用 Key 与 api.tmdb.org/3，留空即使用默认值；也可填自己的 Key 或免密代理，中文封面会随语言切换。

代理地址填到接口根路径即可，例如 https://你的域名/3 或自带参数的 https://你的域名/api?token=xxx；插件会正确拼接 find/tt…、search/movie 等路径，并保留代理原有查询参数。官方域名会自动补 /3。

默认关闭，不记录任何日志、开销最低。开启后：运行日志页 会按「事项」分区显示每次请求的路径 / 参数 / 底层接口 / 响应统计。诊断信息只写入日志，不会作为一条流出现在播放列表里。

3. 目录与播放

片源默认直连：源站 302 到 CDN，带 CORS / Range，客户端可直接播；仅当某些客户端播不动时再勾选代理。

安装

在 Stremio 中安装

打开运行日志 →（仅 debug 版有内容）。安装后在客户端点播放，回到日志页即可看到这次请求的分区：路径 / 参数 / 上游接口 / 响应条数与耗时。

字幕同时随播放源下发（stream.subtitles）：即使客户端不主动请求 /subtitles，播放器里也能选到中英字幕。

插件升级后请在客户端「删除并重新安装」本 addon：manifest 版本号已更新并强制重新校验，仅重启服务不会让客户端重拉资源声明，旧缓存会导致客户端根本不发起字幕请求。重新生成上方链接再安装即可。
