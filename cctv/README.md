# 央视片库 Stremio Addon

将央视网片库的**纪录片、电视剧、动画片、特别节目**，以及 **4K 专区（电视剧4K / 纪录片4K / 科教4K）**整理为 Stremio **剧集（series）** 片源。每集提供按真实分辨率命名的播放源，支持全库关键词搜索。

## 内容类型

| 目录 | 数据源 | 子分类维度 |
|------|--------|-----------|
| 央视纪录片 | jishi.cctv.com 纪实片库 | 人文历史/人物/军事/探索/社会/自然/时政/经济/科技 |
| 央视电视剧 | tv.cctv.com/yxg/dsj | 地区（全部/内地/港澳台/欧美/其他） |
| 央视动画片 | tv.cctv.com/yxg/dhp | 地区（全部/内地/港澳台/欧美） |
| 央视特别节目 | tv.cctv.com/yxg/tbjm | 类型（新闻/经济/综艺/体育/军事/影视/科教等） |
| **电视剧4K** | **tv.cctv.com/4K/index.shtml 同源 API** | 无（独立目录，83 条） |
| **纪录片4K** | 同上 | 无（独立目录，88 条） |
| **科教4K** | 同上 | 无（独立目录，4 条） |
| 央视片库搜索 | 以上五类聚合 | 关键词（标题/简介/主演匹配） |

### 4K 专区说明

央视 4K 专区页面混排新闻、纪录片、综艺、体育等，因此本 addon 拆成 **三个独立目录**：电视剧4K（83 条）、纪录片4K（88 条）、科教4K（4 条），其余分类不加入。

条目本身来自接口的「最新一集」VIDE 链接，但 4K 单集页会通过 JS 动态加载完整分集。addon 复刻了这条链路：

1. `videoinfoByGuid?serviceId=cctv4k&guid=<guid>` → 取 `album_id` 与专辑简介；
2. `getVideoListByAlbumIdNew?id=<album_id>&serviceId=cctv4k&p=<p>&n=12` → 分页取**完整分集**，每集带缩略图。

因此点开 4K 目录中的任一条目，会看到**整部剧的全部集数**（实测《绝密使命》32 集、《考古公开课》53 集、《山海经奇》16 集），每集都有独立缩略图。

该专区流质量也确实更高：master m3u8 提供 **1920×1080（4000kbps）** 与 **1280×720（2048kbps）** 两档，stream 名称按真实分辨率显示。

## 启动

```bash
npm install
node index.js
```

默认监听 **7120** 端口，可用 `PORT` 环境变量修改：

```bash
PORT=7777 node index.js
```

## 在 Stremio 中安装

1. 确保运行 addon 的主机与电视在同一局域网，且电视可访问该主机的 IP。
2. 在 Stremio 中进入 **插件（Addons）** → **安装自定义插件（Install Addon）**。
3. 先打开配置页：`http://<主机IP>:7120/configure`，按需勾选要启用的 catalog 与画质档位，点击「生成安装链接」。
4. 点击生成的 **在 Stremio 中安装**，或复制形如 `http://<主机IP>:7120/<配置JSON>/manifest.json` 的链接手动安装。
5. 安装后首页只显示已勾选的目录（默认全选）：**央视纪录片 / 央视电视剧 / 央视动画片 / 央视特别节目 / 电视剧4K / 纪录片4K / 科教4K / 央视片库搜索**。各目录上方的筛选栏可按子分类过滤。
6. 点开一部节目进入详情页，选择某一集播放；播放时只会出现已勾选的画质档位。
7. **搜索**：在 Stremio 顶部搜索框输入关键词，会返回跨五类片库的匹配结果（如「海洋」「西游记」「汽车」）；前提是在配置页启用了「央视片库搜索」。

> **重要**：如果之前安装过旧版本，需先卸载再重新安装。配置写在安装链接里，修改配置后必须重新生成链接并卸载重装，否则 Stremio 会继续使用旧 manifest 缓存。v3.4.0 起日志默认关闭，需要在配置页勾选才会记录。

## 数据结构

- **内容类型**：`series`（剧集），每个专辑的 meta 包含 `videos` 分集列表。
- **分集**：每集 ID 内编码了单集页面地址，播放时按需解析，无需预加载整个专辑。
- **画质档位**：每集返回两组源——
  1. **稳定源**（`流畅 xxx [档位号]`）：`hls.cntv.lxdns.com/asp/hls/` 路径，不花屏。注意：普通内容的 2000/1200 档实测只有 480x270（档位号是标称码率，非真实分辨率），850 档为 640x360；4K 内容的 4000 档是真实 1920x1080。
  2. **原画源**（`原画 720P/1080P [档位号] 网页源·已解密`）：官方 h5e/enc 加密路径，经本地 wasm 解密后提供**真实 720P/1080P**。这是 v3.3.0 新增，彻底解决花屏的同时获得网页端同款高画质。
- **花屏根因与解密（v3.3.0）**：央视 h5e/hls 分片经 **H5e 加密**（wasm 按 NALU 加密），直接解码会花屏（`non-existing SPS` / `error while decoding MB`），并非码流损坏。addon 内嵌官方 wasm 解密器（`lib/vendor/h5e_bundle.js`），通过本地代理 `/h5e/m3u8/...`、`/h5e/ts/...` 实时下载并解密分片，再用 wasm 解密（`lib/h5e-decryptor.js`，串行队列保证 session 安全）。实测：解密前 ffprobe 6 个解码错误/纯灰画面，解密后 0 错误/清晰 1280x720。
- **代理地址**：stream 返回的代理 URL 使用客户端访问 addon 的 host（局域网 IP）；可用 `ADDON_HOST=192.168.x.x:7120` 环境变量显式指定（多网卡/反向代理场景）。
- **播放路径**：稳定源走 `asp/hls/` 并逐档探测可用性；原画源走解密代理，二者并存供切换。
- **排序**：每集 stream 按**真实分辨率从高到低**排列（1080P → 720P → 640x480 → 640x360 → 480x270），同分辨率时宽度大、带宽高的优先；不再把低画质稳定源放在高画质前面。
- **过期 URL 兼容**：部分老旧分集的日期路径已失效，源站只返回 `window.location.href='...'` 的 JS 跳转桩页。addon 会自动跟随到真实页面再解析 guid，这类分集也能正常返回播放源。
- **分页**：catalog 遵循 Stremio 协议按 `skip` 分页，每页 100 条（可用 `CATALOG_PAGE_SIZE` 环境变量调整）。这是目录能正常显示的关键——一次性返回全部条目会被 Stremio 丢弃。

## 工作原理

1. **catalog**：
   - 纪录片：抓取片库各分类栏目页（VIDA 链接），缓存 6 小时。
   - 电视剧/动画片/特别节目：调用 `api.cntv.cn/list/getVideoAlbumList` 接口，返回结构化数据，支持子分类过滤，缓存 6 小时。
   - 4K 专区：调用 `api.cntv.cn/NewVideo/getLastVideoList4K`（分页拉取 3 页），按 `fc` 字段过滤出电视剧/纪录片/科教，分到三个独立 catalog；点开后用 `videoinfoByGuid` + `getVideoListByAlbumIdNew` 解析完整分集与缩略图，缓存 6/12 小时。
   - 所有目录按 `skip` 参数分页，每页 100 条。
2. **search**：聚合五类片库数据，按标题/简介/主演/地区/年份关键词匹配（央视无公开搜索 API，采用本地过滤），返回前 300 条。
3. **meta**：抓取专辑页或单集页，提取标题、封面、简介及分集列表，缓存 12 小时。
4. **stream**：从单集页提取 `guid`（若页面是 JS 跳转桩页则先跟随到真实地址），调用央视接口 `vdn.apps.cntv.cn/api/getHttpVideoInfo.do` 换取 HLS 地址，优先解析 `manifest.hls_enc_url` / `hls_h5e_url` 的真实多码率 master，返回与真实分辨率相符的流并按画质降序排列，缓存 30 分钟。任一步骤失败都会写入 `STREAM` 日志并写明失败原因、完整 API URL 与页面 URL。

分集解析使用并发池，单集播放地址通常在 1 秒内返回。播放地址由央视 CDN 动态签发，缓存过期后自动重新解析。

## 配置、调试与诊断

### 配置页

浏览器打开 `http://<主机IP>:7120/configure`：

- **Catalog**：8 个目录独立开关，默认全选；关闭的目录不会出现在 manifest，也不会响应 catalog 请求。
- **画质**：6 组画质独立开关——稳定源 1080P/640x360/480x270，网页加密源真 1080P/720P/480P 及以下。默认全选，另有「推荐组合」按钮（稳定源 1080P + 640x360 + 网页源 1080P/720P）。
- **Stream 与加密/代理**：三个开关按优先级生效——
  1. `streamEnabled` 总开关：关闭后 addon 返回空 stream，全部交给本地 provider；
  2. `encryptedUrl` 加密 URL 开关：关闭后所有 h5e 加密源整体移除，只剩直连稳定源；
  3. `decryptProxy` 解密代理开关：**仅在加密 URL 开启时有意义**——开启时 h5e 源改写为 addon 的 `/h5e/m3u8/...` 代理 URL（视频字节过服务器）；关闭时返回原始 `asp/h5e/` URL 并带 `behaviorHints.h5eEncrypted=true`，由电视端原生解密层处理，服务器零视频流量。
- **实时日志**：默认关闭，勾选后生成带 debug 的安装链接，日志页才会有内容。

> **VPS 部署推荐**：保留「addon 提供 stream」+「提供加密 URL」，关闭「解密代理」——服务器只传 JSON，真 720P/1080P 由电视本机解密。若电视端**尚未**安装原生解密层，必须保持代理开启，否则加密源会花屏。

配置以 URL 路径形式保存（`/<配置JSON>/manifest.json`），不上传服务器；生成链接后需要在 Stremio 中删除并重新安装 addon。

**重新调整配置**：在 Stremio 的插件页点击本 addon 的「配置 / Configure」图标即可再次打开配置页，表单会自动回填当前配置。此时 Stremio 访问的是 `/<配置JSON>/configure`（把安装链接里的 `manifest.json` 替换成 `configure`），addon 同时支持该路径与不带前缀的 `/configure`。修改后点击「生成安装链接」，仍需卸载并重新安装 addon 才会生效。

### 实时日志（默认关闭）

日志系统 v3.4.0 起**默认完全关闭**：不写终端、不写文件、不进内存缓冲。开启方式：

1. 配置页勾选「开启实时日志」，用生成的链接打开 `/api/logs?format=html`；
2. 临时排查：访问 `http://<主机IP>:7120/api/logs?enable=1`，对当前进程开启，重启后自动关闭；用 `?disable=1` 关闭。

实时日志页参考 hyperTv 实现，按「事项」分区，支持级别过滤、关键词过滤、显示详情、暂停、清空、按序号增量轮询；轮询本身不写日志。日志内容包括：

- **HTTP**：完整 URL、query、IP、UA、状态码、耗时、字节数与响应摘要。
- **UPSTREAM**：每个源站接口的完整 URL、HTTP 状态、字节数、耗时、缓存命中，失败时单独标红。
- **REDIRECT**：老旧分集 URL 的 JS 跳转链（原始 URL → 最终 URL → 跳数）。
- **CATALOG / META / STREAM**：按步骤编号输出数据源读取、meta 生成、分页、分集解析、画质过滤、代理改写。stream 为 0 时会输出 `步骤 2a/2b/2c 失败` 及具体原因（无 guid / API 异常 / 所有档位不可用），并带上完整 API URL。
- **H5EPROXY**：m3u8 改写前后的完整 URL、TS 下载字节数、wasm 解密结果与耗时。

### 命令行健康检查

在服务目录运行：

```bash
node health.js
node health.js http://192.168.6.125:7120
node health.js --json
```

脚本会逐步检查并打印 `PASS / FAIL / SKIP`：configure 页面 → manifest → 用户配置过滤 → catalog/分页/搜索 → meta 分集 → stream 与画质过滤（含**画质降序**、**过期日期 URL 自动跟随 JS 跳转**、**三开关四种组合**回归用例）→ H5e m3u8 改写 → TS 下载与 wasm 解密 → ffprobe 真分辨率复核 → 央视播放 API / 4K 列表 API / yxg 列表 API → 日志开关与实时日志页。任一项失败退出码为 1，可直接定位到具体步骤和接口 URL。当前结果：**47 PASS / 0 FAIL / 0 SKIP**。

### 在线自检

浏览器访问 `http://<主机IP>:7120/_diagnostics`，返回 JSON 简版自检报告（manifest、纪录片/4K/yxg 数量、meta 解析、搜索）。深度排查请用 `health.js`。

**环境变量**：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 监听端口 | `7120` |
| `LOG_ENABLED` | 进程启动时是否开启日志（一般不需要，优先用配置页） | `0` |
| `LOG_LEVEL` | 日志开启后的终端输出级别（TRACE/DEBUG/INFO/WARN/ERROR） | `INFO` |
| `CATALOG_PAGE_SIZE` | catalog 每页条数 | `100` |

## 说明

- 该 addon 仅解析央视网公开可访问的播放地址，不存储、不转存任何视频内容。
- 少量早期专辑页面已失效（返回空页或 404），这类条目的分集列表会为空，属正常现象。日志会记录 `HTTP 404 for ...`，可据此确认是源站问题而非 addon 故障。
- 4K 专区接口不提供可用的专辑页（VIDA 全 404），addon 通过其单集页内的动态接口还原完整分集；若该动态接口失效，条目会退化为 1 集。
- 仅供家庭个人观看使用，请遵守相关版权规定。
